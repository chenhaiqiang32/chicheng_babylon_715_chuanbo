# Babylon.js 灯光系统使用文档

本文档结合 [Babylon.js Light 官方 API](https://doc.babylonjs.com/typedoc/classes/BABYLON.Light) 与项目 `src/3d/app/index.ts` 中的实际用法，介绍灯光类型、通用参数、以及场景中的日照与天空联动。

---

## 1. 灯光系统概述

Babylon.js 的 **Light** 是所有灯光的基类，用于控制场景中物体的照明与颜色。默认场景最多允许 **4 盏灯**，可在需要时提高上限。

- **官方文档**: https://doc.babylonjs.com/typedoc/classes/BABYLON.Light  
- **灯光介绍**: [Lights Introduction](https://doc.babylonjs.com/features/featuresDeepDive/lights/lights_introduction)  
- **继承关系**: `Node` → `Light`；子类包括 `HemisphericLight`、`DirectionalLight`（通过 `ShadowLight`）、`PointLight`、`SpotLight`、`AreaLight` 等。

本项目主要使用 **HemisphericLight**（环境光）和 **DirectionalLight**（平行光/太阳光），并与 **SkyMaterial** 联动实现日升日落。

## 2. 基类 Light 构造函数

### 2.1 签名

```ts
new Light(
  name: string,
  scene?: Scene,
  dontAddToScene?: boolean
): Light
```

### 2.2 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| **name** | `string` | 是 | 灯光名称，用于调试与 Inspector。 |
| **scene** | `Scene` | 否 | 灯光所属场景，通常必传以正确渲染。 |
| **dontAddToScene** | `boolean` | 否 | 为 `true` 时不把灯光加入场景。 |

## 3. 基类 Light 通用属性与访问器

以下属性和访问器对所有灯光类型通用（部分在 PBR 材质下才有明显作用）。

### 3.1 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| **diffuse** | `Color3` | 漫反射颜色，影响物体基础受光色。 |
| **specular** | `Color3` | 高光颜色。注意：**不影响 PBR 材质**。 |
| **intensity** | `number` | 光强。默认使用引擎单位；PBR 下可用 `intensityMode` 指定物理单位。 |
| **falloffType** | `number` | 衰减类型，见下方常量。仅对 PBR 材质有效。 |
| **id** | `string` | 节点 ID。 |
| **name** | `string` | 节点名称。 |
| **metadata** | `any` | 用户自定义元数据。 |
| **state** | `string` | 用户自定义状态字符串。 |
| **animations** | `Animation[]` | 关联的动画列表。 |
| **renderPriority** | `number` | 渲染优先级，灯光过多时可用于回退或排序。 |

### 3.2 衰减类型常量（falloffType）

| 常量 | 值 | 说明 |
|------|----|------|
| **Light.FALLOFF_DEFAULT** | 0 | 按材质规范衰减：Standard 用标准衰减，PBR 可按材质指定。 |
| **Light.FALLOFF_PHYSICAL** | 1 | 物理衰减：距离平方反比。 |
| **Light.FALLOFF_GLTF** | 2 | 按 glTF PBR 规范衰减，便于与其他引擎互操作。 |
| **Light.FALLOFF_STANDARD** | 3 | 与 Standard 材质一致的衰减。 |

### 3.3 强度模式常量（intensityMode，仅 PBR 有效）

| 常量 | 值 | 说明 |
|------|----|------|
| **Light.INTENSITYMODE_AUTOMATIC** | 0 | 按灯光类型自动：点光/聚光用光强，平行光用照度。 |
| **Light.INTENSITYMODE_LUMINOUSPOWER** | 1 | 光通量：流明 (lm)。 |
| **Light.INTENSITYMODE_LUMINOUSINTENSITY** | 2 | 光强：坎德拉 (cd, lm/sr)。 |
| **Light.INTENSITYMODE_ILLUMINANCE** | 3 | 照度：勒克斯 (lux, lm/m²)。 |
| **Light.INTENSITYMODE_LUMINANCE** | 4 | 亮度：尼特 (cd/m²)。 |

### 3.4 光照图模式常量（lightmapMode）

| 常量 | 值 | 说明 |
|------|----|------|
| **Light.LIGHTMAP_DEFAULT** | 0 | 光照贴图在其它光照计算之后做加减/乘（由材质决定）。 |
| **Light.LIGHTMAP_SPECULAR** | 1 | 光照贴图仅作漫反射；此灯只加高光与动态阴影。 |
| **Light.LIGHTMAP_SHADOWSONLY** | 2 | 光照贴图作为唯一照明；此灯只加动态阴影。 |

### 3.5 访问器（get/set）

| 访问器 | 类型 | 说明 |
|--------|------|------|
| **excludedMeshes** | `AbstractMesh[]` | 不受此光影响的网格列表。 |
| **includedOnlyMeshes** | `AbstractMesh[]` | 仅受此光影响的网格（设置后仅这些网格受该光影响）。 |
| **excludeWithLayerMask** | `number` | 按层 ID 排除网格；0 表示不启用。 |
| **includeOnlyWithLayerMask** | `number` | 按层 ID 仅包含网格；0 表示不启用。 |
| **intensityMode** | `number` | PBR 下光强的物理单位（见上表常量）。 |
| **lightmapMode** | `number` | 光照图模式（见上表常量）。 |
| **radius** | `number` | PBR 下模拟软面积光的半径。 |
| **range** | `number` | 光的影响距离（场景单位）。PBR 材质使用平方反比衰减，此值在 PBR 下未使用。 |
| **shadowEnabled** | `boolean` | 是否启用此光的阴影（不销毁 ShadowGenerator 即可开关）。 |
| **isVisible** | `boolean` | 节点是否可见。 |
| **parent** | `Node \| null` | 父节点。 |

### 3.6 灯光类型 ID（getTypeID）

| 常量 | 值 | 说明 |
|------|----|------|
| **Light.LIGHTTYPEID_POINTLIGHT** | 0 | 点光源。 |
| **Light.LIGHTTYPEID_DIRECTIONALLIGHT** | 1 | 平行光。 |
| **Light.LIGHTTYPEID_SPOTLIGHT** | 2 | 聚光灯。 |
| **Light.LIGHTTYPEID_HEMISPHERICLIGHT** | 3 | 半球光。 |
| **Light.LIGHTTYPEID_RECT_AREALIGHT** | 4 | 矩形面积光。 |

## 4. HemisphericLight（半球光）

模拟来自天空/地面的环境光，无位置，只有方向；常用于整体环境照明。

### 4.1 构造函数

```ts
new HemisphericLight(
  name: string,
  direction: Vector3,
  scene: Scene
): HemisphericLight
```

| 参数 | 类型 | 说明 |
|------|------|------|
| **name** | `string` | 灯光名称。 |
| **direction** | `Vector3` | 光的方向，通常指向上方天空，如 `(0, 1, 0)` 或 `(0, -1, 0)`。 |
| **scene** | `Scene` | 所属场景。 |

### 4.2 特有属性

| 属性 | 类型 | 说明 |
|------|------|------|
| **groundColor** | `Color3` | “地面”方向（即 -direction）的颜色，与 diffuse 一起形成上下半球渐变。 |

### 4.3 本项目中的用法

```544:545:src/3d/app/index.ts
    const light = new HemisphericLight('light', new Vector3(0, -1, 0), this.scene);
```

- 方向 `(0, -1, 0)` 表示光从下方来，常用于配合地面或室内环境。若需要“天空在上”的感觉，可改为 `(0, 1, 0)`。
- 创建后可通过 `light.diffuse`、`light.groundColor`、`light.intensity` 微调。

## 5. DirectionalLight（平行光）

从无穷远沿某一方向照射，无衰减，适合模拟太阳。

### 5.1 构造函数

```ts
new DirectionalLight(
  name: string,
  direction: Vector3,
  scene: Scene
): DirectionalLight
```

| 参数 | 类型 | 说明 |
|------|------|------|
| **name** | `string` | 灯光名称。 |
| **direction** | `Vector3` | 光的传播方向（光线沿此方向照射）。 |
| **scene** | `Scene` | 所属场景。 |

### 5.2 特有说明

- **position**：平行光可设置 position，用于阴影贴图等；光照方向由 **direction** 决定。
- **direction**：需在运行时根据太阳位置更新时，应使用 `direction.copyFrom(...)` 避免创建新对象。

### 5.3 本项目中的用法

```559:563:src/3d/app/index.ts
    let sun = this.scene.lights.find((l) => l instanceof DirectionalLight) as DirectionalLight;
    if (!sun) {
      sun = new DirectionalLight('sunLight', new Vector3(0, -1, 0), this.scene);
      sun.intensity = 1.0;
    }
```

- 若场景中已有平行光（如从 GLB 加载），则复用；否则创建 `sunLight`，初始方向 `(0, -1, 0)`，强度 1。
- 建议将得到的 `sun` 赋给 `this.sunLight`，以便在 `updateSkyByTime` 中与天空球联动（见下节）。

## 6. 与 SkyMaterial 联动（日照与强度）

本项目在 `updateSkyByTime` 中根据时间计算太阳位置与高度角，并同步 **SkyMaterial** 与 **DirectionalLight**。

### 6.1 太阳方向与强度

```832:862:src/3d/app/index.ts
  private updateSkyByTime() {
    if (!this.skyMaterial) return;
    const now = new Date();
    // ... 根据日出/日落时间计算 elev、yaw、pitch ...
    const sunPos = new Vector3(cp * sy, sp, cp * cy).scale(radius);
    this.skyMaterial.sunPosition = sunPos;
    const lum = 0.2 + 0.8 * elev;
    const turb = 2 + 4 * (1 - elev);
    this.skyMaterial.luminance = lum;
    this.skyMaterial.turbidity = turb;
    this.skyMaterial.rayleigh = 2 + 1 * elev;
    this.skyMaterial.mieCoefficient = 0.005;
    this.skyMaterial.mieDirectionalG = 0.8;
    if (this.sunLight) {
      const dir = sunPos.normalize().scale(-1);
      this.sunLight.direction.copyFrom(dir);
      this.sunLight.intensity = 0.2 + 0.8 * elev;
    }
  }
```

- **sunPosition**：传给 SkyMaterial，用于天空着色。
- **direction**：平行光方向取 `-sunPos.normalize()`，即“从太阳指向场景”。
- **intensity**：随仰角 `elev` 在 0.2～1.0 之间线性变化，模拟早晚变暗、正午最亮。

### 6.2 SkyMaterial 相关参数（与“灯光”视觉一致）

| 属性 | 说明 |
|------|------|
| **sunPosition** | 太阳位置（Vector3），与平行光 direction 反向一致。 |
| **luminance** | 天空亮度。 |
| **turbidity** | 浑浊度，影响大气散射。 |
| **rayleigh** | 瑞利散射系数。 |
| **mieCoefficient** | 米氏散射系数。 |
| **mieDirectionalG** | 米氏散射方向性。 |

## 7. 常用方法（基类 Light）

| 方法 | 说明 |
|------|------|
| **getAbsolutePosition()** | 返回灯光在世界空间中的位置（Vector3）。 |
| **getShadowGenerator()** | 获取关联的阴影生成器（若有）。 |
| **canAffectMesh(mesh)** | 判断某网格是否受此光影响。 |
| **clone(name, newParent?)** | 克隆灯光。 |
| **dispose(doNotRecurse?, disposeMaterialAndTextures?)** | 释放资源。 |
| **setEnabled(boolean)** | 启用/禁用灯光。 |
| **getScaledIntensity()** | 获取考虑 intensityMode 后的缩放强度。 |

## 8. 其它灯光类型简要说明

- **PointLight**：点光源，有 position 和 range，可设衰减。
- **SpotLight**：聚光灯，有 position、direction、角度与衰减。
- **ShadowLight**：DirectionalLight / SpotLight 等可投射阴影的基类，需配合 `ShadowGenerator` 或 `CascadedShadowGenerator` 使用。

项目中在注释中曾对 `ShadowGenerator`、`CascadedShadowGenerator` 与灯光绑定有预留逻辑，实际阴影配置可按需在对应模块中扩展。

## 9. 参数速查小结

| 需求 | 建议 |
|------|------|
| 环境光 | 使用 **HemisphericLight**，设置 `direction`、`diffuse`、`groundColor`、`intensity`。 |
| 太阳/室外主光 | 使用 **DirectionalLight**，设置 `direction`、`intensity`，并与 SkyMaterial 的 `sunPosition` 同步。 |
| PBR 物理单位 | 设置 **intensityMode**（如照度、光强），再设 **intensity**。 |
| 只照部分物体 | 使用 **includedOnlyMeshes** 或 **includeOnlyWithLayerMask**。 |
| 排除某些物体 | 使用 **excludedMeshes** 或 **excludeWithLayerMask**。 |
| 软阴影/面积光感 | 在 PBR 下可设置 **radius**。 |
| 阴影开关 | 使用 **shadowEnabled**，无需移除 ShadowGenerator。 |
