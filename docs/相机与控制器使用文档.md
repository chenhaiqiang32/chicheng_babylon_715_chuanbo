# 相机与控制器使用文档

本文档结合 [Babylon.js Camera 官方 API](https://doc.babylonjs.com/typedoc/classes/BABYLON.Camera) 与项目 `src/3d/app/index.ts`、`src/3d/Editor.ts` 中的实际用法，介绍相机类型、构造参数、输入控制（控制器）以及编辑器中的控制模式。

---

## 1. 概述

项目中涉及两种使用场景：

- **App 场景**（`src/3d/app/index.ts`）：加载 GLB/FBX 模型时，若场景尚未创建，会默认创建一个 **ArcRotateCamera**，并绑定到 canvas 上，用于环绕观察模型。
- **Editor 场景**（`src/3d/Editor.ts`）：编辑器支持 **ArcRotateCamera**（环绕相机）和 **UniversalCamera**（第一人称/通用相机），可添加、切换激活相机，并与 Gizmo 控制模式配合使用。

**控制器** 包含两方面含义：

1. **相机输入控制器**：通过 `attachControl` 绑定的鼠标/触摸/滚轮等输入，控制相机旋转、平移、缩放（ArcRotate）或行走（Universal）。
2. **编辑器控制模式**（ControlMode）：选择、移动、旋转、缩放等 Gizmo 模式，用于编辑场景中的物体，与相机控制共用同一画布。

---

## 2. ArcRotateCamera（环绕相机）

围绕目标点旋转、可缩放距离的相机，适合模型展示与场景浏览。

### 2.1 构造函数

```ts
new ArcRotateCamera(
  name: string,
  alpha: number,
  beta: number,
  radius: number,
  target: Vector3,
  scene?: Scene
): ArcRotateCamera
```

### 2.2 构造参数

| 参数 | 类型 | 说明 |
|------|------|------|
| **name** | `string` | 相机名称，用于调试与层级显示。 |
| **alpha** | `number` | 水平旋转角度（弧度），绕 Y 轴，0 为默认朝向。 |
| **beta** | `number` | 垂直旋转角度（弧度），绕 X 轴，范围建议 `0.1`～`π - 0.1`，避免极轴翻转。 |
| **radius** | `number` | 相机到目标点的距离（场景单位）。 |
| **target** | `Vector3` | 相机注视的目标点，通常为场景中心或模型中心。 |
| **scene** | `Scene` | 所属场景。 |

### 2.3 项目中的使用示例

**App（`src/3d/app/index.ts`）— 加载模型时创建默认相机：**

```ts
const camera = new ArcRotateCamera(
  'camera',
  -Math.PI / 2,   // alpha：初始水平角
  Math.PI / 2.5,  // beta：初始俯仰角
  15,              // radius：初始距离
  Vector3.Zero(),  // target：原点
  scene,
);
camera.attachControl(this.canvas, true);
camera.maxZ = 10000;
scene.activeCamera = camera;
```

**Editor（`src/3d/Editor.ts`）— 新建场景或添加相机：**

```ts
const camera = new ArcRotateCamera(
  name ? name : 'camera',
  0,
  0,
  0,
  new Vector3(0, 0, 0),
  this.scene,
);
camera.setPosition(new Vector3(30, 30, -5)); // 可选：直接设位置
camera.minZ = 0.001;
camera.maxZ = 5000;
camera.lowerRadiusLimit = 0.01;
camera.upperRadiusLimit = 5000;
camera.inertia = 0.4;
camera.panningInertia = 0.5;
camera.wheelPrecision = 0;
camera.wheelDeltaPercentage = 0.1;
camera.pinchDeltaPercentage = 0.1;
camera.attachControl();
```

### 2.4 ArcRotateCamera 常用属性（含控制器相关）

| 属性 | 类型 | 说明 |
|------|------|------|
| **target** | `Vector3` | 相机注视的目标点。 |
| **alpha** | `number` | 当前水平角（弧度）。 |
| **beta** | `number` | 当前垂直角（弧度）。 |
| **radius** | `number` | 当前相机到目标点的距离。 |
| **minZ** | `number` | 近裁剪面距离。 |
| **maxZ** | `number` | 远裁剪面距离。 |
| **lowerRadiusLimit** | `number` | 缩放时半径下限（滚轮/ pinch 不能小于该值）。 |
| **upperRadiusLimit** | `number` | 缩放时半径上限。 |
| **inertia** | `number` | 旋转惯性系数，0～1，越大惯性越强。 |
| **panningInertia** | `number` | 平移惯性系数。 |
| **wheelPrecision** | `number` | 滚轮缩放精度（数值越大，同样滚轮位移对应缩放变化越大；0 表示按比例缩放）。 |
| **wheelDeltaPercentage** | `number` | 滚轮缩放时半径变化比例（与 wheelPrecision 配合）。 |
| **pinchDeltaPercentage** | `number` | 触屏双指缩放时半径变化比例。 |
| **useAutoRotationBehavior** | `boolean` | 是否启用自动旋转（如预览用）。 |

### 2.5 相机输入（ArcRotateCameraInputsManager）

通过 `camera.inputs` 可访问并配置输入，常用子对象：

| 输入类型 | 说明 | 可调参数示例 |
|----------|------|-----------------------------|
| **ArcRotateCameraMouseWheelInput** | 滚轮缩放 | 见上节 `wheelPrecision`、`wheelDeltaPercentage`。 |
| **ArcRotateCameraPointersInput** | 左键旋转、右键/中键平移 | `panningSensibility`（平移灵敏度，Inspector 中“拖拽阻力”对应 1/灵敏度）。 |
| **ArcRotateCameraKeyboardInput** | 键盘控制（若启用） | 方向键等。 |

Inspector 中「拖拽阻力」绑定为：`inputs.attached.pointers.panningSensibility`（值 1～1000，数值越大平移越不灵敏）。

## 3. UniversalCamera（第一人称/通用相机）

支持 WASD 行走、鼠标朝向，适合第一人称漫游；可配合碰撞与重力。

### 3.1 构造函数

```ts
new UniversalCamera(
  name: string,
  position: Vector3,
  scene?: Scene
): UniversalCamera
```

### 3.2 构造参数

| 参数 | 类型 | 说明 |
|------|------|------|
| **name** | `string` | 相机名称。 |
| **position** | `Vector3` | 初始世界坐标位置。 |
| **scene** | `Scene` | 所属场景。 |

### 3.3 项目中的使用示例（Editor）

```ts
const camera = new UniversalCamera(
  name ? name : '1stCamera',
  new Vector3(0, 1, -5),
  this.scene,
);
camera.speed = 1;
camera.inertia = 0;
camera.keysUp.push(87);    // W
camera.keysDown.push(83);  // S
camera.keysLeft.push(65);  // A
camera.keysRight.push(68); // D
camera.keysUpward.push(69);   // E 上升
camera.keysDownward.push(81); // Q 下降
camera.checkCollisions = true;
camera.ellipsoid = new Vector3(0.4, 1.2, 0.4);
```

### 3.4 UniversalCamera 常用属性

| 属性 | 类型 | 说明 |
|------|------|------|
| **speed** | `number` | 键盘移动速度。 |
| **inertia** | `number` | 移动惯性。 |
| **keysUp / keysDown / keysLeft / keysRight** | `number[]` | 上下左右键 keyCode 数组。 |
| **keysUpward / keysDownward** | `number[]` | 垂直升降键 keyCode（如 E/Q）。 |
| **checkCollisions** | `boolean` | 是否与场景碰撞体检测碰撞。 |
| **ellipsoid** | `Vector3` | 碰撞椭球体半径（x, y, z）。 |
| **applyGravity** | `boolean` | 是否应用重力。 |
| **minZ** | `number` | 近裁剪面。 |
| **maxZ** | `number` | 远裁剪面。 |
| **fov** | `number` | 视场角（弧度）。 |

## 4. 相机基类与通用接口

### 4.1 attachControl / detachControl

绑定或解绑画布上的输入，使相机响应鼠标/触摸/键盘。

```ts
// 绑定到 canvas，noPreventDefault = true 表示不阻止默认事件（如页面滚动）
camera.attachControl(canvas?: HTMLCanvasElement, noPreventDefault?: boolean): void;

// 解绑
camera.detachControl(): void;
```

- **App**：`camera.attachControl(this.canvas, true)`，绑定到 App 的 canvas。
- **Editor**：`scene.activeCamera.attachControl()`，绑定到引擎默认 canvas；切换场景或相机时会先 `detachControl()` 再对新的 `activeCamera` 执行 `attachControl()`。

### 4.2 通用相机属性（Camera 基类）

| 属性 | 类型 | 说明 |
|------|------|------|
| **minZ** | `number` | 近裁剪面。 |
| **maxZ** | `number` | 远裁剪面。 |
| **fov** | `number` | 视场角（弧度），透视相机有效。 |
| **id** | `string` | 节点 ID。 |
| **name** | `string` | 节点名称。 |
| **position** | `Vector3` | 世界坐标位置。 |
| **globalPosition** | `Vector3` | 世界坐标（只读）。 |

Inspector 中相机面板会展示：**fov**、**minZ**、**maxZ**、**拖拽阻力**（panningSensibility）；UniversalCamera 额外展示 **speed**、**collision**、**gravity**。

## 5. 编辑器中的相机 API（Editor）

### 5.1 添加与激活相机

| 方法 | 说明 |
|------|------|
| **addCamera(name?: string)** | 添加 ArcRotateCamera 并设为 activeCamera（下一帧生效）。 |
| **addUniversalCamera(name?: string)** | 添加 UniversalCamera 并设为 activeCamera。 |
| **activeCamera(camera: Camera)** | 将指定相机设为 `scene.activeCamera`，并执行 detach/attach 与派发 `onActiveCameraChanged`。 |

### 5.2 事件

- **onActiveCameraChanged**：`{ newUuid: string; oldUuid: string }`，激活相机切换时派发，用于层级树等更新当前相机图标状态。

### 5.3 场景与相机的关系

- 从资源反序列化场景时（`setScene` / `getScene`），`scene.activeCamera` 由资源中的 `activeCamera` UUID 决定，若未指定则取 `scene.cameras[0]`。
- 相机序列化通过 `camera.serialize()` 存入节点 `data`，反序列化使用 `Camera.Parse(node.data, scene)`（见 `src/3d/assets/serialze/node/Camera.ts`）。

## 6. 编辑器控制模式（ControlMode）

与相机输入不同，控制模式用于在 **当前视图** 下对 **场景中的物体** 进行选择、移动、旋转、缩放，通过 Gizmo 与 `GizmoManager` 实现。

### 6.1 枚举定义（`src/store/useSceneModule/useControl.ts`）

| 枚举值 | 说明 |
|--------|------|
| **ControlMode.Select** | 选择模式：关闭所有 Gizmo，仅可点选物体。 |
| **ControlMode.Move** | 移动模式：开启位置 Gizmo，可平移选中物体。 |
| **ControlMode.Rotate** | 旋转模式：开启旋转 Gizmo，可旋转选中物体。 |
| **ControlMode.Scale** | 缩放模式：开启缩放 Gizmo，可缩放选中物体。 |

### 6.2 切换逻辑（Editor.switchControlType）

- **Select**：关闭 position/rotation/scale Gizmo，并设置视图标志为 None。
- **Move**：仅启用 positionGizmo。
- **Rotate**：仅启用 rotationGizmo，并设置 `updateGizmoRotationToMatchAttachedMesh = false`。
- **Scale**：仅启用 scaleGizmo。

通过 `useScene().setCurrentControlMode(ControlMode.xxx)` 切换模式后，会触发 `switchControlType`，从而更新 Gizmo 的启用状态。相机仍由 `attachControl` 的输入控制（旋转、平移、缩放等），与 ControlMode 互不替代。

## 7. 参数速查表

### 7.1 ArcRotateCamera 常用参数

| 参数/属性 | 类型 | 默认/示例 | 说明 |
|-----------|------|-----------|------|
| name | string | `'camera'` | 名称 |
| alpha | number | `-Math.PI/2` / `0` | 水平角（弧度） |
| beta | number | `Math.PI/2.5` / `0` | 垂直角（弧度） |
| radius | number | `15` / `0` | 到目标距离 |
| target | Vector3 | `Vector3.Zero()` | 目标点 |
| minZ | number | `0.001`～`0.01` | 近裁剪面 |
| maxZ | number | `5000`～`10000` | 远裁剪面 |
| lowerRadiusLimit | number | `0.01` | 最小半径 |
| upperRadiusLimit | number | `5000` | 最大半径 |
| inertia | number | `0.4` | 旋转惯性 |
| panningInertia | number | `0.5` | 平移惯性 |
| wheelPrecision | number | `0` | 滚轮精度（0 为比例缩放） |
| wheelDeltaPercentage | number | `0.1` | 滚轮缩放比例 |
| pinchDeltaPercentage | number | `0.1` | 双指缩放比例 |
| panningSensibility | number | — | 平移灵敏度（pointers 输入） |

### 7.2 UniversalCamera 常用参数

| 参数/属性 | 类型 | 示例 | 说明 |
|-----------|------|------|------|
| name | string | `'1stCamera'` | 名称 |
| position | Vector3 | `(0, 1, -5)` | 初始位置 |
| speed | number | `1` | 移动速度 |
| inertia | number | `0` | 移动惯性 |
| checkCollisions | boolean | `true` | 是否碰撞检测 |
| ellipsoid | Vector3 | `(0.4, 1.2, 0.4)` | 碰撞体半径 |
| keysUp/Down/Left/Right | number[] | W/S/A/D keyCode | 水平移动键 |
| keysUpward/Downward | number[] | E/Q keyCode | 垂直移动键 |
| applyGravity | boolean | — | 是否应用重力 |

### 7.3 控制模式（ControlMode）

| 模式 | 说明 |
|------|------|
| Select | 选择物体，Gizmo 全关 |
| Move | 位置 Gizmo，平移物体 |
| Rotate | 旋转 Gizmo，旋转物体 |
| Scale | 缩放 Gizmo，缩放物体 |
