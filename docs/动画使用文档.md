# 动画使用文档（多模型与 AnimationGroup）

本文档说明本项目中 **GLB/FBX 模型动画** 的加载、存储与播放方式，包括 `src/3d/app/index.ts` 中的 App 动画 API、`src/view/app/index.vue` 的前端用法，以及底层使用的 [Babylon.js AnimationGroup](https://doc.babylonjs.com/typedoc/classes/BABYLON.AnimationGroup) 的常用参数与方法。

---

## 1. 项目内动画流程概览

- 使用 **Babylon.js** 的 `ImportMeshAsync` 加载 `.glb` / `.gltf` / `.fbx`，得到 `result.animationGroups`。
- 每个模型按 **模型名称** 在 App 内存储为一组 `AnimationGroup[]`；无动画的模型也会被记录（空数组），便于在 UI 中统一按模型切换。
- 前端通过 **模型名称** 选择当前模型，再按 **动画名称** 选择并播放/停止动画；播放与速率控制均按模型维度区分。

---

## 2. App 类动画 API（`src/3d/app/index.ts`）

### 2.1 加载模型与场景：`loadModelAndScene`

从 GLB/FBX 地址加载模型并创建或复用场景，支持多模型、按名称存储动画（或无动画模型）。

```ts
async loadModelAndScene(
  modelUrl: string,
  modelNameOrOnProgress?: string | ((progress: number) => void),
  onProgress?: (progress: number) => void,
): Promise<Scene>
```

| 参数 | 类型 | 说明 |
|------|------|------|
| **modelUrl** | `string` | 模型完整 URL，支持 `.glb` / `.gltf` / `.fbx`。 |
| **modelNameOrOnProgress** | `string \| ((progress: number) => void)` | 可选。若为 `string`，用作该模型的存储名称；若为函数，视为进度回调（此时与 `onProgress` 等价）。 |
| **onProgress** | `(progress: number) => void` | 可选。加载进度回调，`progress` 为 0～1。 |

**行为说明：**

- 第一次调用会创建 Scene、相机并执行 `setGround()`；后续调用在同一场景中追加模型。
- 模型名称：若未传 `modelName`，则从 URL 推断（去掉路径与扩展名，如 `./Dancing.fbx` → `Dancing`）。
- **带动画**：`result.animationGroups` 非空时，以 `Map<模型名称, AnimationGroup[]>` 存储。
- **不带动画**：同样写入 Map，值为空数组 `[]`，保证该模型名称可在 UI 中显示与切换。

**示例：**

```ts
// 单模型，名称自动从 URL 推断
await App.Instance.loadModelAndScene('./Dancing.fbx', (p) => { loading.value = p; });

// 多模型，分别加载并存储
for (const url of ['./Dancing.fbx', './Soldier.glb']) {
  await App.Instance.loadModelAndScene(url, (p) => { loading.value = p; });
}

// 显式指定模型名称
await App.Instance.loadModelAndScene('./Soldier.glb', 'Soldier', (p) => {});
```

### 2.2 按模型获取动画名称：`getAnimationNames`

获取指定模型（或当前激活模型）的动画名称列表。

```ts
getAnimationNames(modelName?: string): string[]
```

| 参数 | 类型 | 说明 |
|------|------|------|
| **modelName** | `string` | 可选。不传则使用当前激活模型名称。 |

**返回：** 该模型下所有 `AnimationGroup` 的 `name` 组成的数组；无动画或模型不存在时返回 `[]`。

---

### 2.3 获取已加载模型名称列表：`getModelNames`

```ts
getModelNames(): string[]
```

返回当前已注册的所有模型名称（包括无动画的模型）。

---

### 2.4 设置/获取当前激活模型：`setCurrentModel` / `getCurrentModelName`

```ts
setCurrentModel(modelName: string): void
getCurrentModelName(): string | null
```

- **setCurrentModel**：将指定模型设为“当前模型”；仅当该名称已存在于内部 Map 时生效。UI 切换模型时应调用，以便后续 `playAnimation` 等默认作用于该模型。
- **getCurrentModelName**：返回当前激活的模型名称。

---

### 2.5 获取动画帧范围：`getAnimationFrameRange`

获取指定动画的原始帧区间，用于设置裁剪的起始帧、结束帧。

```ts
getAnimationFrameRange(
  modelName?: string,
  nameOrIndex?: string | number
): { from: number; to: number } | null
```

| 参数 | 类型 | 说明 |
|------|------|------|
| **modelName** | `string` | 可选。不传则使用当前激活模型。 |
| **nameOrIndex** | `string \| number` | 可选。动画名称或索引；不传或传 `-1` 表示第一个动画。 |

**返回：** 该动画的 `from`（首帧）、`to`（末帧）；无动画或模型不存在时返回 `null`。

---

### 2.6 播放动画：`playAnimation`

在指定模型上播放指定动画（按名称或索引），支持**按起始帧/结束帧裁剪**播放区间。播放前会先停止该模型上的所有动画。

```ts
playAnimation(
  nameOrIndex?: string | number,
  loop?: boolean,
  modelName?: string,
  direction?: 'forward' | 'backward',
  fromFrame?: number,
  toFrame?: number
): void
```

| 参数 | 类型 | 说明 |
|------|------|------|
| **nameOrIndex** | `string \| number` | 可选。动画名称或索引；不传或传 `-1` 时播放该模型第一个动画。 |
| **loop** | `boolean` | 是否循环，默认 `false`。 |
| **modelName** | `string` | 可选。不传则使用当前激活模型。 |
| **direction** | `'forward' \| 'backward'` | 播放方向，默认 `'forward'`。 |
| **fromFrame** | `number` | 可选。裁剪起始帧（含）；不传则使用动画原始 `from`。 |
| **toFrame** | `number` | 可选。裁剪结束帧（含）；不传则使用动画原始 `to`。 |

内部根据 `direction` 与裁剪区间调用 `AnimationGroup.start(loop, speedRatio, from, to)`；进度与跳帧均在裁剪后的区间内计算。

---

### 2.7 倒放动画：`playAnimationReverse`

以倒放方式播放动画的便捷方法，同样支持裁剪区间。

```ts
playAnimationReverse(
  nameOrIndex?: string | number,
  loop?: boolean,
  modelName?: string,
  fromFrame?: number,
  toFrame?: number
): void
```

等价于 `playAnimation(nameOrIndex, loop, modelName, 'backward', fromFrame, toFrame)`。

---

### 2.8 停止动画：`stopAllAnimations`

```ts
stopAllAnimations(modelName?: string): void
```

| 参数 | 类型 | 说明 |
|------|------|------|
| **modelName** | `string` | 可选。传入则仅停止该模型的动画；不传则停止所有已加载模型的动画。 |

内部对每个目标调用 `AnimationGroup.stop()`。

---

### 2.9 设置播放速率：`setAnimationSpeed`

```ts
setAnimationSpeed(speed: number, modelName?: string): void
```

| 参数 | 类型 | 说明 |
|------|------|------|
| **speed** | `number` | 速率，`1` 为原速。 |
| **modelName** | `string` | 可选。不传则对所有模型的动画组设置 `speedRatio`。 |

对应 Babylon 的 `AnimationGroup.speedRatio`。

## 3. 前端使用（`src/view/app/index.vue`）

### 3.1 数据与计算

| 变量 | 类型 | 说明 |
|------|------|------|
| **modelNames** | `Ref<string[]>` | 已加载模型名称列表，在多个模型加载完成后赋值为 `App.Instance.getModelNames()`。 |
| **currentModelName** | `Ref<string>` | 当前选中的模型名称，与下拉框 `v-model` 绑定。 |
| **animationNames** | `ComputedRef<string[]>` | 当前模型的动画名称列表，依赖 `currentModelName` / `getCurrentModelName()` 与 `getAnimationNames(name)`。 |
| **currentAnimName** | `Ref<string>` | 当前选中的动画名称，与动画下拉框绑定。 |
| **clipFrom** / **clipTo** | `Ref<number>` | 裁剪起始帧、结束帧，与“裁剪”输入框绑定；播放时传入 `playAnimation(..., fromFrame, toFrame)`。 |
| **loadedAsModel** | `Ref<boolean>` | 是否为“按模型 URL 加载”的流程（决定是否显示模型/动画 UI）。 |

### 3.2 多模型加载示例

```ts
const modelUrls = ['./Dancing.fbx', './Soldier.glb', './DamagedHelmet.glb'];
if (isModelUrl(url)) {
  for (const mUrl of modelUrls) {
    await App.Instance.loadModelAndScene(mUrl, (progress) => {
      loading.value = progress;
    });
  }
  loadedAsModel.value = true;
  modelNames.value = App.Instance.getModelNames();
  currentModelName.value = App.Instance.getCurrentModelName() || '';
}
```

### 3.3 裁剪功能

- **裁剪区间**：通过“起始帧 / 结束帧”两个数字框设置播放区间，正放、倒放都会在该区间内播放。
- **默认不裁剪**：切换模型或动画时，会自动将裁剪区间设为该动画的完整 `from`～`to`，即默认播放整段。
- **恢复完整**：点击“恢复完整”会将起始帧/结束帧重新设为该动画的完整 `from`～`to`。
- **获取范围**：`App.Instance.getAnimationFrameRange(modelName, nameOrIndex)` 可获取动画原始帧范围，用于初始化或校验输入。

### 3.4 交互逻辑

- **切换模型**（`onModelChange`）：调用 `App.Instance.setCurrentModel(currentModelName.value)`，清空 `currentAnimName`，并执行 `updateClipRangeToDefault()` 更新裁剪默认值。
- **播放**（`playCurrentAnim`）：用当前模型名、当前动画名（或第一个）、当前裁剪区间调用 `App.Instance.playAnimation(..., 'forward', clipFrom.value, clipTo.value)`。
- **倒放**（`playCurrentAnimReverse`）：同上，方向为 `'backward'`，同样传入当前裁剪区间。
- **停止**（`stopAnim`）：用当前模型名调用 `App.Instance.stopAllAnimations(name)`，无模型名时 `stopAllAnimations()` 停止全部。

## 4. Babylon.js AnimationGroup 参考

本项目从 `ImportMeshAsync` 得到的动画组即为 [BABYLON.AnimationGroup](https://doc.babylonjs.com/typedoc/classes/BABYLON.AnimationGroup) 实例，用于在多个目标上协调播放动画。以下为与本项目相关的属性与方法摘要，完整 API 见官方文档。

### 4.1 构造函数

```ts
new AnimationGroup(
  name: string,
  scene?: Nullable<Scene>,
  weight?: number,
  playOrder?: number
)
```

| 参数 | 类型 | 说明 |
|------|------|------|
| **name** | `string` | 动画组名称（与 `getAnimationNames()` 返回的名称一致）。 |
| **scene** | `Nullable<Scene>` | 可选，所属场景。 |
| **weight** | `number` | 可选，动画权重，默认 -1 表示不使用权重。 |
| **playOrder** | `number` | 可选，播放顺序，默认 0。 |

### 4.2 常用属性

| 属性 | 类型 | 说明 |
|------|------|------|
| **name** | `string` | 动画组名称。 |
| **metadata** | `any` | 用户自定义元数据。 |
| **uniqueId** | `number` | 节点唯一 ID。 |

### 4.3 常用访问器（Getter/Setter）

| 访问器 | 类型 | 说明 |
|--------|------|------|
| **speedRatio** | `number` | 播放速率，1 为原速；本项目通过 `setAnimationSpeed()` 设置。 |
| **loopAnimation** | `boolean` | 是否循环；本项目通过 `playAnimation(_, loop)` 传入 `start(loop)`。 |
| **isPlaying** | `boolean` | 当前是否正在播放。 |
| **isStarted** | `boolean` | 是否已启动过。 |
| **from** / **to** | `number` | 首帧/末帧，可用于裁剪播放区间。 |
| **targetedAnimations** | `TargetedAnimation[]` | 本组包含的“动画+目标”列表。 |
| **animatables** | `Animatable[]` | 由本组控制的 Animatable 列表。 |
| **enableBlending** | `Nullable<boolean>` | 是否与当前动画混合。 |
| **blendingSpeed** | `Nullable<number>` | 混合速度。 |
| **weight** | `number` | 动画权重。 |
| **mask** | `Nullable<AnimationGroupMask>` | 用于过滤参与动画的对象。 |
| **isAdditive** | `boolean` | 是否以叠加方式计算。 |

### 4.4 常用方法

| 方法 | 签名摘要 | 说明 |
|------|----------|------|
| **start** | `start(loop?: boolean, speedRatio?: number, from?: number, to?: number, isAdditive?: boolean): AnimationGroup` | 开始播放；本项目使用 `group.start(loop)`。 |
| **stop** | `stop(skipOnAnimationEnd?: boolean): AnimationGroup` | 停止播放；本项目通过 `stopAllAnimations()` 调用。 |
| **play** | `play(loop?: boolean): AnimationGroup` | 从初始状态播放；未启动则 start，已暂停则 restart。 |
| **pause** | `pause(): AnimationGroup` | 暂停。 |
| **restart** | `restart(): AnimationGroup` | 暂停后重新开始。 |
| **reset** | `reset(): AnimationGroup` | 重置到初始状态。 |
| **goToFrame** | `goToFrame(frame: number, useWeight?: boolean): AnimationGroup` | 跳转到指定帧（需在播放或暂停状态）。 |
| **getLength** | `getLength(from?: number, to?: number): number` | 获取时长（秒），可选帧范围。 |
| **getCurrentFrame** | `getCurrentFrame(): number` | 当前帧（多动画不同步时可能不准确）。 |
| **clone** | `clone(newName, targetConverter?, cloneAnimations?, cloneAnimationKeys?): AnimationGroup` | 克隆动画组。 |
| **dispose** | `dispose(): void` | 释放资源。 |

### 4.5 可观察对象（Observable）

| Observable | 说明 |
|------------|------|
| **onAnimationEndObservable** | 单个动画结束时触发（TargetedAnimation）。 |
| **onAnimationGroupEndObservable** | 本组所有动画都结束时触发。 |
| **onAnimationGroupLoopObservable** | 本组所有动画循环一次时触发。 |
| **onAnimationGroupPauseObservable** | 本组暂停时触发。 |
| **onAnimationGroupPlayObservable** | 本组开始播放时触发。 |
| **onAnimationLoopObservable** | 单个动画循环时触发。 |

如需在播放结束或循环时做逻辑，可直接在获取到的 `AnimationGroup` 上订阅上述 Observable。

### 4.6 静态方法（裁剪/合并等）

- **AnimationGroup.ClipFrames**：按帧范围裁剪并生成新动画组。
- **AnimationGroup.ClipFramesInPlace**：在原动画组上按帧范围裁剪。
- **AnimationGroup.MergeAnimationGroups**：合并多个动画组。
- **AnimationGroup.Parse**：从序列化数据解析动画组。

更多静态方法见 [AnimationGroup 官方文档](https://doc.babylonjs.com/typedoc/classes/BABYLON.AnimationGroup)。

## 5. 小结

- **加载**：`loadModelAndScene(modelUrl, modelNameOrOnProgress?, onProgress?)`，按模型名称存储动画组（或无动画则空数组）。
- **查询**：`getModelNames()`、`getAnimationNames(modelName?)`、`getCurrentModelName()`、`getAnimationFrameRange(modelName?, nameOrIndex?)`（获取动画帧范围，用于裁剪）。
- **切换当前模型**：`setCurrentModel(modelName)`。
- **播放/倒放/停止/速率**：`playAnimation(nameOrIndex?, loop?, modelName?, direction?, fromFrame?, toFrame?)`（支持裁剪与方向）、`playAnimationReverse(...)`、`stopAllAnimations(modelName?)`、`setAnimationSpeed(speed, modelName?)`。
- **裁剪**：通过 `fromFrame`、`toFrame` 传入起始帧与结束帧即可只播放该区间；前端默认使用完整区间（不裁剪），可点击“恢复完整”将输入框重置为完整范围。
- **底层**：上述接口内部操作的是 Babylon.js 的 `AnimationGroup`，裁剪对应 `start(loop, speedRatio, from, to)` 的 `from`/`to` 参数；其余与官方 [AnimationGroup API](https://doc.babylonjs.com/typedoc/classes/BABYLON.AnimationGroup) 一致。
