# 3D 信息牌子使用文档

本文档说明项目中 **3D 信息牌** 的封装与用法：在场景中为指定模型生成带连接线的信息牌，显示设备名称（title）与属性键值对（attribute）；通过 `onMessage` 接收数据并驱动更新。

- **实现位置**：`src/3d/app/InfoBoardHelper.ts`、`src/3d/app/index.ts`、`src/view/app/index.vue`
- **依赖**：Babylon.js（DynamicTexture、MeshBuilder、StandardMaterial 等）

---

## 1. 功能概述

- 每个信息牌对应一条数据，通过 **id** 匹配场景中的节点（模型/网格），牌子底部有一根 **连线** 从牌子底部连接到该节点位置。
- 牌面使用 **Babylon GUI（AdvancedDynamicTexture + Rectangle/TextBlock）** 绘制：可选显示 **设备名称（title）**，以及多行 **属性（attribute）**，每行为 `key: value`。
- GUI 信息牌是 **屏幕空间渲染**：**不会近大远小**，同时通过 `linkWithMesh` **跟随模型**。
- 数据通过 **onMessage**（`window` 的 `message` 事件）接收，格式为数组；也可在业务代码中直接调用 `App.Instance.setInfoBoards(data)`。

---

## 2. 数据格式

### 2.1 单条牌子数据：`InfoBoardItem`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| **id** | `string` | 是 | 唯一标识，用于匹配场景节点（节点 `uuid`）及牌子复用；找不到对应节点时该条不创建牌子。 |
| **title** | `string` | 否 | 设备名称，显示在牌面第一行；不传或空则不显示标题行。 |
| **attribute** | `Array<Record<string, unknown>>` | 是 | 属性列表，每项为单键值对对象 `{ key: value }`，牌面上显示为多行 `key: value`。 |

### 2.2 数组格式

```ts
[
  {
    id: "节点-uuid-或-名称",
    title: "设备名称",
    attribute: [
      { "温度": "25°C" },
      { "状态": "运行中" },
    ],
  },
  {
    id: "另一个节点-id",
    attribute: [{ "压力": "101 kPa" }],
  },
]
```

- **id**：必须与场景中要挂接的节点的 **uuid** 一致（如从编辑器或 GLB 来的节点 id），这样牌子和连线才会绑定到该节点并随其移动。
- **attribute**：每项一个对象，可多键，但通常用单键值对，多行即多个对象。

## 3. 通过 onMessage 接收数据

视图层（`src/view/app/index.vue`）已注册 `window.addEventListener('message', ...)`，支持两种 payload：

1. **直接数组**：`event.data` 为 `InfoBoardItem[]`。
2. **带类型包装**：`event.data` 为 `{ type: 'infoBoards', data: InfoBoardItem[] }`。

收到合法数据后会调用 `App.Instance.setInfoBoards(data)`，自动创建/更新/删除牌子。

**示例（父页面或 iframe 通信）：**

```js
// 父页面向 iframe 发送信息牌数据
const iframe = document.querySelector('iframe');
iframe.contentWindow.postMessage(
  [
    { id: 'mesh-uuid-xxx', title: '泵机 A', attribute: [{ 转速: '1200 rpm' }, { 温度: '42°C' }] },
  ],
  '*'
);

// 或使用包装格式
iframe.contentWindow.postMessage(
  { type: 'infoBoards', data: [/* ... */] },
  '*'
);
```

## 4. App 类 API（`src/3d/app/index.ts`）

### 4.1 设置信息牌数据：`setInfoBoards`

根据数据创建/更新/删除牌子；**id** 与场景节点匹配的才会创建，连线从牌子底部连到该节点。

```ts
setInfoBoards(data: InfoBoardItem[]): void
```

| 参数 | 类型 | 说明 |
|------|------|------|
| **data** | `InfoBoardItem[]` | 牌子数据数组，见 §2。 |

- 若某 **id** 在本次 `data` 中不存在，对应牌子会被移除。
- 若某 **id** 在场景中找不到对应节点，该条不会创建牌子。

---

### 4.2 设置信息牌样式：`setInfoBoardStyle`

设置牌子外观（纹理尺寸、平面尺寸、颜色、字体等）。**会重建牌子辅助并清空当前牌子**，需再调用 `setInfoBoards` 才会重新显示并应用新样式。

```ts
setInfoBoardStyle(options: InfoBoardStyleOptions): void
```

| 参数 | 类型 | 说明 |
|------|------|------|
| **options** | `InfoBoardStyleOptions` | 样式选项，见 §5。 |

---

### 4.3 清空信息牌：`clearInfoBoards`

移除当前所有 3D 信息牌。

```ts
clearInfoBoards(): void
```

---

### 4.4 按 id 控制显示/隐藏：`setInfoBoardsVisible`

根据传入的 id 数组，控制哪些牌子显示、哪些隐藏。

```ts
setInfoBoardsVisible(visibleIds: string[]): void
```

| 参数 | 类型 | 说明 |
|------|------|------|
| **visibleIds** | `string[]` | 需要显示的牌子 id 数组；为空数组表示全部隐藏。 |

- 仅影响 **可见性**，不会销毁牌子对象，本次隐藏的牌子下次 `setInfoBoards` 仍可更新内容后再显示。

## 5. 样式参数：`InfoBoardStyleOptions`

在 `InfoBoardHelper` 或 `App.setInfoBoardStyle` 中传入，未传则使用默认值。

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| **widthPx** | `number` | `260` | 牌子宽度（像素）。 |
| **heightPx** | `number` | `140` | 牌子高度（像素）。 |
| **minWidthPx** | `number` | `220` | 牌子最小宽度（像素），用于内容自适应时的下限。 |
| **maxWidthPx** | `number` | `420` | 牌子最大宽度（像素），用于内容自适应时的上限。 |
| **linkOffsetYPx** | `number` | `-70` | 牌子相对目标节点的像素偏移（向上为负）。 |
| **overlapGroup** | `number` | `1` | GUI overlapGroup，用于同组牌子自动避让不重叠。 |
| **backgroundColor** | `string` | `'rgba(13, 16, 22, 0.82)'` | 牌面背景色（支持 rgba）。 |
| **borderColor** | `string` | `'rgba(96, 165, 250, 0.95)'` | 牌面边框颜色。 |
| **titleColor** | `string` | `'#ffffff'` | 标题（title）文字颜色。 |
| **attributeColor** | `string` | `'rgba(219, 234, 254, 0.95)'` | 属性行文字颜色。 |
| **titleFontSize** | `number` | `16` | 标题字号（px）。 |
| **attributeFontSize** | `number` | `12` | 属性字号（px）。 |
| **paddingPx** | `number` | `10` | 统一内边距（像素，若同时设置 paddingXPx/paddingYPx 会被它们覆盖）。 |
| **paddingXPx** | `number` | `10` | 左右内边距（像素）。 |
| **paddingYPx** | `number` | `6` | 上下内边距（像素）。 |
| **lineGapPx** | `number` | `2` | 属性行间距（像素）。 |
| **titleCharSpacing** | `number` | `1.2` | 标题字间距（通过插入细空格模拟）。 |
| **attributeCharSpacing** | `number` | `1.04` | 属性字间距（通过插入细空格模拟）。 |

## 7. 使用示例

### 7.1 在业务代码中直接设置牌子

```ts
import { App, type InfoBoardItem } from '@/3d/app';

const data: InfoBoardItem[] = [
  {
    id: 'scene 中某节点的 uuid',
    title: '电机 1',
    attribute: [
      { 功率: '5.2 kW' },
      { 转速: '1500 rpm' },
      { 温度: '38°C' },
    ],
  },
];
App.Instance.setInfoBoards(data);
```

### 7.2 自定义样式后再设置数据

```ts
App.Instance.setInfoBoardStyle({
  widthPx: 260,
  minWidthPx: 220,
  maxWidthPx: 420,
  linkOffsetYPx: -70,
  backgroundColor: 'rgba(10, 20, 40, 0.95)',
  borderColor: '#00ff88',
  titleFontSize: 16,
  attributeFontSize: 12,
  paddingXPx: 10,
  paddingYPx: 6,
});
App.Instance.setInfoBoards(data);
```

### 7.3 清空牌子

```ts
App.Instance.clearInfoBoards();
```

### 7.4 仅控制部分牌子显示

```ts
// 假设现有多个牌子，其 id 分别为 'a' | 'b' | 'c'
// 只显示 a 和 c
App.Instance.setInfoBoardsVisible(['a', 'c']);

// 全部隐藏
App.Instance.setInfoBoardsVisible([]);
```

## 8. 实现说明（供扩展参考）

- **InfoBoardHelper**（`src/3d/app/InfoBoardHelper.ts`）：维护 `Map<id, BoardEntity>`，每个 entity 包含一个 GUI `Rectangle`（牌子本体）、一个 GUI `Line`（连接线）以及若干 `TextBlock`；牌子位置通过 `linkWithMesh` 跟随目标 mesh。
- 使用 **Babylon GUI**：`AdvancedDynamicTexture.CreateFullscreenUI` 创建全屏 UI；每个牌子由 `Rectangle + StackPanel + TextBlock` 构成，属性文本支持内容自适应宽度、字间距、自适应高度；连线用 GUI 的 `Line`（`connectedControl = rect` + `linkWithMesh(mesh)` + `dash` 实现淡化虚线，从牌子底部居中连到模型上）。
