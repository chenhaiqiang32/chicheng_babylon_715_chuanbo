CZZ 垂直阵运行联动 C009H

        

          格式：{ cmd:"C009H", param:{ clcdRaw, ... } }。首次收到会触发
          20new / Animation 正放并记录阈值；运行中按 clcdRaw 更新
          rope_1；回到阈值及以下时倒放并隐藏 5206H 牌子。
        

        
        

          
        

        
TTZ 托体阵运行联动 C011H

        

          格式：{ cmd:"C011H", param:{ tlsfcdRaw, ... } }。首次收到会触发
          donghua02new / donghua02_first 正放并记录阈值；开机动画结束后创建绳子 demo
          rope_3（02fromA → donghua02-011）；运行中按
          tlsfcdRaw 更新绳长；回到阈值及以下时移除绳子并倒放动画。

接收阵 5202H（cgqArray 共 34 项）

        

          格式：{ cmd:"5202H", param:{ localDateTime, cgqArray:[{fgsszRaw,fysszRaw,hxsszRaw,sdsszRaw}, …×34] } }。hx→水平角
          yaw，fy→俯仰 pitch，sd→深度 depth；段长由引擎按默认累加。
        

        
        

          
          
        


        
接收阵 JSZ 收放设备 C010H

        

          请先 switchCamera → jsz 并发送 5202H 生成柔性绳。托缆逻辑需
          firxzjcztRaw:"0" 且已存在柔性绳。firxzjcztRaw：
          1 释放 / 2 回收（显示 donghua03new 的
          lansheng02，隐藏柔性绳 Tube）；0 停止并隐藏
          lansheng02、显示柔性绳。托缆开机：donghua01new / Animation 正放结束后创建
          rope_2（01fromA→donghua01-004）。
